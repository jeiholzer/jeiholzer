I spent years as a web developer before moving into project management, so I'm as comfortable in a design discussion with the dev team as I am walking stakeholders through scope, risk and schedule. ## What I've worked on

Most recently I managed delivery for HUD Exchange at ICF, a federal platform supporting HUD's grantee programs. That meant leading the team through an Agile adoption, defining what "done" meant for each release, running user acceptance testing, planning staffing, and working with our technical director on security compliance for the ATO. The work was funded across about nine separate HUD funding lines, so keeping priorities, effort and budget aligned was a big part of the job.

Before moving into the PM role I was a developer on that same kind of work, building and maintaining web applications and the databases behind them. Earlier, on the Army's AIM system at ALTESS, I helped design the database and wrote some of the original applications.

Today I work as an independent consultant, taking on both project management and development engagements.
